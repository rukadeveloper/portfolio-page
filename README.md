# 포트폴리오 페이지

개인 포트폴리오를 소개하는 현대적인 웹사이트입니다. 프로젝트, 기술 스택, 경력 정보를 시각적으로 효과적으로 표현합니다.

**🔗 [라이브 데모](https://portfolio-page-ten-henna.vercel.app/)**

## ✨ 주요 기능

- 🎨 반응형 디자인 (모바일 / 태블릿 / 데스크톱)
- 📱 모바일 메뉴 네비게이션
- 🎬 부드러운 애니메이션 효과
- 📊 프로젝트 및 경력 소개
- 🎯 섹션별 스크롤 네비게이션
- 💬 모달 기반 프로젝트 상세 정보
- 🌙 다크모드 지원

## 🛠️ 기술 스택

- **Frontend Framework**: React 19
- **Language**: TypeScript
- **Styling**: Styled-Components
- **State Management**: Zustand
- **UI Components**: Radix UI, Lucide React, React Icons
- **Routing**: React Router DOM
- **Build Tool**: React Scripts
- **Animation**: AOS (Animate On Scroll)
- **CSS Utility**: Tailwind CSS Merge

## 📦 설치 및 실행

### 요구사항
- Node.js 16+
- npm 또는 yarn

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm start
```
브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

### 프로덕션 빌드
```bash
npm build
```

## 📁 프로젝트 구조

```
src/
├── components/
│   ├── private/      # 페이지 섹션 컴포넌트
│   ├── shared/       # 공유 UI 컴포넌트 (헤더, 네비게이션 등)
│   └── ui/           # UI 기본 컴포넌트
├── reset/            # 전역 스타일
├── libs/             # 유틸 함수
└── App.tsx          # 메인 애플리케이션
```
